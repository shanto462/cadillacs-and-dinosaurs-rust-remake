# M5-03: boss intro services

B50 is the dialogue dispatcher at 0x844B4. This task covers variants 0, 1, 2 and 4.
0x84504 chooses the rightmost player with live byte exactly 1, using signed X and keeping
an earlier player on a tie. The selected hero stays fixed for the conversation. Portrait
printing uses 0x84736 and the existing tall printer at 0x84F72. The portrait palette, mouth
and eye patches, dialogue state pointers and strings are read from dino.zip at runtime.
The line timer and attack edge test are 0x84910. No RNG calls are made by either service.

B76 is the handler at 0x89EDE, found through the pool B dispatch table at 0x2362E.
It is a backdrop flash rather than a camera pan. Init at 0x89EF2 saves the far-layer X and
Y words in the object, makes live equal 2, then enters the first substate in the same frame.
The substate at 0x89F24 fills two regions of the alternate scroll3 map through 0x8A03C,
sets a ten-tick word counter and immediately decrements it. Each fill uses DBRA and writes
one cell beyond a four-kilobyte region. The runtime tables at 0x8A020 and 0x8A02E select
the tile code and attribute by variant.

The countdown at 0x89F58 alternates the alternate backdrop at zero scroll with the saved
normal backdrop on multiples of four. It changes G.$28 (layer control), G.$2E (scroll3
base), G.$7E4 (scroll3 X) and G.$7E8 (scroll3 Y), plus the object's flash byte. At zero it
still applies the flash before advancing the substate. On the following frame 0x89FBE
restores the normal layer control, normal map base and saved scroll words. It leaves the
flash byte set. The next frame frees the object through 0x8A062 / 0x4938.

The alternate map needs a small Vram field and a presentation bank-selection hook. Its
snapshot load and trace output preserve the fill's extra cell and all other map contents.

The original boss call sites belong to the boss ports: Vice 0x426CC, Butcher 0x38F54,
Slice 0x4BF5A. The current placeholder bosses skip their introductions. This service task
does not add an approximate intro to those placeholders. Ending B50 variant 7 and other
conversations are outside this task.

The background update at 0x2042E follows pool B in the frame. In normal scroll3 states it
recomputes G.$7E4 and G.$7E8 after B76 wrote them. End-of-frame comparisons must include
that camera update; the saved object coordinates and the bank and layer-control writes
still come from B76.
