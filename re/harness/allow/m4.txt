# 5. Open
#   - the hit mode (section 4) would need the a6 left by every routine that runs before the passes. It changes only the pan sweep direction.
#   - class 19 catch timing (Episode 7), class 61 talk timer (Episode 2) and the tally counter start are timing differences of other tasks.
#   - the differences of unported classes go with their class tasks (M6 to M8); the list of classes is in the "unported class" cause above.
#   - the attract filter: MAME decides at the flush (0x610, G.$4CC at that moment, one request a frame, only when the Z80 mailbox is free), the
#     port at the request. The request streams above equal MAME in every code of the attract loop and the select, so no case showed up, but the
#     Z80 mailbox itself (the writes to 0xF18001) was not tapped. A request queued in the frame where G.$4CC changes could differ.
#
