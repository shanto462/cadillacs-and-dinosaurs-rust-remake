# M9-06: open item probe sweep A (player, weapons, items, front end)

Written 2026-10-13 (task M9-06 of `D5-final-plan.md`, lane B). This file answers the open items that D2a s19, D2c s21, D2b s11, D4a s13 and D4d s15 left for a MAME run.
Every answer has a source tag: **M:** = measured in MAME (segment names are given), **R:** = read in the program code. No ROM bytes are copied here, only addresses, frame
numbers and measured numbers. The port was read as it is today (one code worker is editing `dino-rs` at the same time, so file names may move).

## 0. How it was run

Six headless MAME processes (the limit), one per batch, with `re/harness/probe/probe.sh` (SDL dummy drivers, no GUI). The inputs are in `re/out/probe/_input/`, the logs in
`re/out/probe/m906_a` to `m906_f` (git-ignored, not committed). All frame numbers are probe frames `t` after the jump (t = 0 is the first frame of control).

| batch | input file | segments | content |
| --- | --- | --- | --- |
| a | `m906_a.txt` | 65 | dive scan, wall jump places, tag team with weapons, friendly fire with weapons, thrown barrel, torch charge, torch burn |
| b | `m906_b.txt` | 52 | barrel depth, wall retests, boss weapon factors, stones, food above 100 HP, enemy swing against a container, Episode 5 gate, 3 player drum |
| c | `m906_c.txt` | 20 | death in the Cadillac, dizzy, continue quirk (first try), continue restore (first try), region word |
| d | `m906_d.txt` | 26 | continue quirk and join by attack with absolute addresses, continue restore with a moving camera, stone sizes, Vice, join in the car |
| e | `m906_e.txt` | 8 | Episode 5 gate with the camera walking, wall jump timing of Mustapha in Episode 5 |
| f | `m906_f.txt` | 10 | 3 player friendly fire check, special frame after the start invulnerability, the level that `jump` leaves |

Numbers were read from the `watch` lines of each segment (one row per frame). A short script that prints a row when a field changes was used (it is in the session scratchpad, not in the repo).

Status words: **answered**, **closed earlier** (another design document already had the answer; I checked it against the port and, where cheap, re-ran it), **not reached** (with the reason).
